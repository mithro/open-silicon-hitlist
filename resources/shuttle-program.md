## Projects and repositories
- [Tiny Tapeout](https://tinytapeout.com) — shared-die shuttles on SKY130, IHP, GF180MCU; [GitHub org](https://github.com/TinyTapeout)
- [wafer.space](https://wafer.space) — low-cost GF180MCU full-die runs
- [Caravel](https://github.com/efabless/caravel) and [caravel_user_project](https://github.com/efabless/caravel_user_project) — Open MPW harness
- [SKY130 PDK](https://github.com/google/skywater-pdk), [GF180MCU PDK](https://github.com/google/gf180mcu-pdk), [IHP SG13G2 Open PDK](https://github.com/IHP-GmbH/IHP-Open-PDK) — shuttle nodes
- [Google open silicon](https://developers.google.com/silicon) — Open MPW program home
- [LibreLane](https://github.com/librelane/librelane) — flow used for current shuttles
- [OpenRAM](https://github.com/VLSIDA/OpenRAM) — SRAM IP built and proven via shuttles
- [OpenFASoC](https://github.com/idea-fasoc/OpenFASOC) — analog generators taped out on MPWs
- IEEE SSCS Chipathon (SSCS Open-Source Ecosystem) — yearly design contest feeding shuttles
- Zero to ASIC course (Matt Venn) — https://www.zerotoasiccourse.com
- Efabless chipIgnite / Open MPW (defunct 2025) — historical program
